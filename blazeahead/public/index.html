blazeAhead is a VS Code extension for Claude Code on our network. It keeps your sessions flowing through busy services, sets up your keys for Jira, Confluence, GitLab and Artifactory, maps where things live, and runs your Jira queue through devAgent.

Install in three steps

blazeAhead ships as a .vsix file that you install straight into VS Code.

  1. Download

    Get blazeAhead.vsix and save it anywhere you like.

  2. Install it

    In VS Code, open the Extensions view (Ctrl+Shift+X), click the … menu at its top and choose Install from VSIX…, then pick the file. From a terminal: code --install-extension blazeAhead.vsix.

  3. Reload

    Reload VS Code when it asks. The flame appears in the activity bar: click it to open blazeAhead.

Updating? Install the new .vsix the same way; it replaces the old version.
