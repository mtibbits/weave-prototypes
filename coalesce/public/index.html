Install in three steps

  1. Download

    Get Coalesce.xlam and save it in the folder Excel opens when you click Browse in step 3.

  2. Unblock it

    If Excel blocks its macros, right-click the file, choose Properties, tick Unblock, then click OK.

  3. Add it to Excel

    Go to File → Options → Add-ins. Next to Manage, pick Excel Add-ins and click Go…, then Browse…, choose Coalesce.xlam and click OK.

Updating? Close Excel, download the new version and replace the old file.
